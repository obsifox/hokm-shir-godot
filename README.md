# حکم شیر — Hokm Shir 🃏

بازی سنتی ایرانی **حکم** ساخته‌شده با **Godot 4**، آماده برای خروجی **اندروید**.

## امکانات

- **حالت کلاسیک (۴ نفره):** با تیم، حاکم، کوت و امتیاز تا ۷ ست
- **حالت فانتزی (۴ تا ۸ نفره):** با کارت‌های ویژه (Sp) و ایونت‌های تکاملی (Evo) و دو جوکر
- **هوش مصنوعی ۵ سطحی:** تازه‌کار، کاربلد، بازیکن، حرفه‌ای و جهنمی (با شمارش کامل کارت)
- **بازی محلی (هات‌اسپات):** ساخت میز + جستجوی خودکار میزها روی شبکه محلی
- **دست کارتِ گرد:** سوایپ چپ/راست برای انتخاب کارت، **کشیدن کارت به سمت بالا برای انداختن**
- **دکمه مرتب‌سازی** در وسط بازی (حکم اول / خال / امتیاز)
- **موسیقی و ۲۰ افکت صوتی** (پخش کارت، جمع دنگ، کوت، انتخاب حکم و...)
- **ری‌اکشن‌ها** و انیمیشن‌های هدفمند

## کارت‌های ویژه (فانتزی)

| کارت | اثر |
|---|---|
| سپر | جلوی سکوت/جاسوسی/جابه‌جایی را می‌گیرد |
| سکوت | حریف مجبور به بازی ضعیف‌ترین کارت در دنگ بعدی می‌شود |
| جابه‌جایی | ضعیف‌ترین کارتت با یک کارت تصادفی حریف عوض می‌شود |
| جاسوسی | یکی از کارت‌های مخفی حریف را می‌بینی |
| دو برابر | امتیاز دستِ برنده دو برابر می‌شود |
| طلایی | دنگ بعدی که ببری، ۲ دنگ حساب می‌شود |
| جوکر حکم | قوی‌ترین کارت بازی (در دسته پخش می‌شود) |
| جوکر رنگ | مثل حکم عمل می‌کند؛ از جوکر حکم ضعیف‌تر است |

## ایونت‌های تکاملی (Evo)

- **ممنوع:** تا ۳ دنگ یک خال زمین زدنی نیست
- **دست طلایی:** بیشترین شاه/بی‌بی/سربازِ گرفته‌شده، امتیاز اضافه می‌گیرد
- **برعکس:** چرخش بازی برعکس می‌شود
- **تغییر حاکم:** حاکم دو صندلی جلوتر شروع می‌کند

## باز کردن پروژه

1. **Godot 4.3 یا جدیدتر** را از [godotengine.org](https://godotengine.org/download) نصب کن (نسخه استاندارد کافی است).
2. Godot را باز کن → **Import** → فایل `project.godot` داخل این پوشه را انتخاب کن.
3. صبر کن تا asset ها ایمپورت شوند (اولین بار کمی طول می‌کشد).
4. دکمه **Play (F5)** را بزن — بازی در پنجره عمودی اجرا می‌شود.

## خروجی اندروید (APK)

نیازمندی‌ها:
- JDK 17
- Android SDK (با Platform-Tools و Build-Tools 34)
- قالب‌های خروجی Godot: از منوی `Editor → Manage Export Templates` دانلود کن

مرحله‌ها:
1. `Editor → Editor Settings → Export → Android` → مسیر Java SDK و Android SDK را تنظیم کن.
2. `Project → Export → Android` (پری‌ست آماده است) → **Export Project** → فایل APK ساخته می‌شود.
3. برای نصب روی گوشی، `USB Debugging` را فعال کن یا APK را مستقیم منتقل و نصب کن.

## بازی محلی (هات‌اسپات)

1. همه گوشی‌ها به **یک وای‌فای یا هات‌اسپات** وصل باشند.
2. یک نفر «ساخت میز» را می‌زند؛ بقیه «پیوستن» — میزها خودکار پیدا می‌شوند.
3. اگر پیدا نشد، IP میزبان را دستی وارد کن (در هات‌اسپات معمولاً `192.168.43.1`).
4. میزبان «شروع بازی» را می‌زند؛ صندلی‌های خالی با هوش مصنوعی پر می‌شوند.

## ساختار پروژه

```
hokm_shir/
├── project.godot            # تنظیمات پروژه (۱۰۸۰×۱۹۲۰ عمودی)
├── export_presets.cfg       # پری‌ست آماده اندروید
├── assets/                  # کارت‌ها، پس‌زمینه‌ها، دکمه‌ها، صداها
│   ├── persian_cards/       # ۵۲ کارت ایرانی
│   ├── sp/  ev/             # کارت‌های ویژه و ایونت‌ها
│   ├── sfx/  sounds/        # افکت‌ها و موسیقی
│   └── ...
├── fonts/                   # وزیرمتن
└── src/
    ├── core/                # قوانین، دسته، وضعیت بازی
    ├── ai/                  # هوش مصنوعی ۵ سطحی
    ├── ui/                  # کارت‌نما، دست گرد، آواتار، صدا و...
    ├── net/                 # شبکه محلی (ENet + UDP discovery)
    └── scenes/              # منو، لابی، میز بازی
```

## نحوه بازی

- **انتخاب کارت:** انگشتت را روی دست کارت‌ها به چپ/راست بکش؛ کارت انتخابی بالا می‌آید.
- **انداختن کارت:** کارت انتخابی را **به سمت بالا بکش** و رها کن.
- **حکم:** حاکم از ۵ کارت اولش، خال حکم را انتخاب می‌کند.
- **مرتب‌سازی:** دکمه «مرتب» بالای صفحه؛ هر بار یک چیدمان جدید.
- **کارت ویژه:** در حالت فانتزی، پایین‌سمت راست ظاهر می‌شود؛ در نوبتت رویش بزن.

## بیلد گرفتن اندروید (خودت)

۱. **Godot 4.3** را نصب کن (godotengine.org)
۲. **Export Templates 4.3** را از Tool > Management Export Templates دانلود کن
۳. **Android build template** را نصب کن: منوی Project > Install Android Build Template
۴. JDK **17** و Android SDK (با platforms;android-34 و build-tools;34.0.0) را آماده کن و مسیرها را در Editor Settings > Export > Android تنظیم کن
۵. در `export_presets.cfg` مسیر و رمز keystore خودت را در بخش `keystore/` بگذار (یا خالی بگذار تا Godot با debug key امضا کند)
۶. خروجی: Project > Export > preset «Android» (بیلد Gradle خودکار انجام می‌شود)

> معماری‌ها: پیش‌فرض arm64-v8a + armeabi-v7a فعال است؛ برای کاهش حجم فقط arm64 را نگه دار.
